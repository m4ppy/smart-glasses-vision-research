# Smart Glasses Vision Research

Research repository for computer vision studies related to smart-glass environments.

This repository organizes multiple studies involving object detection, fingerspelling recognition, egocentric vision, and lightweight vision models for wearable applications.

## Studies

### YOLO-Based Fingerspelling Recognition

Comparison of YOLO-based object detection models for recognizing 26 alphabet fingerspelling hand shapes, including an additional YOLOv8n 100-epoch experiment for convergence and class-wise error analysis.

[View study](studies/yolo-fingerspelling-recognition/)
